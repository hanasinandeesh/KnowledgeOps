# Database Details

## 1.1 Initial Tables

| Table | Purpose |
| :--- | :--- |
| `organizations` | Tenant/workspace details |
| `users` | User accounts |
| `roles` | Employee, Manager, Admin |
| `departments` | Department details |
| `user_departments` | Department memberships |
| `documents` | Stable document identity and ownership |
| `document_versions` | Individual document versions |
| `document_access_grants` | Explicit user/role access |
| `chunks` | Authoritative extracted chunk text |
| `ingestion_jobs` | Background ingestion state |
| `conversations` | Private conversation ownership |
| `messages` | User questions and AI answers |
| `feedback` | Answer feedback |
| `audit_logs` | Important security and administrative events |
